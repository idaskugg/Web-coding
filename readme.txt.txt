Edits since 1st attempt:
1. The navigation menu has now been styled. I chose to display in flex, which is a horizontal display instead of vertical as before. The flex-wrap will make sure it fits on smaller screen by breaking it up. Gap, padding and margin adds to the design to make it look better.
2. I removed <strong> in some places where it was used the wrong way. 
3. Because I used italic a lot in my resume page, I decided to style it in CSS (class: "italic text") instead of using <em>. 
4. Because I had inline styling on my images, I instead styled it with CSS. I set a max width to match the length of the paragraphs (because max-width 100% makes the image take up the whole screen), and width 100% makes it fit small screens as well.
5. Target=-blank was added for the social media links so they now open in a new page.
6. Changed the e-mail to mailto:example@example.no
7. Changed from 120ch to 60ch to make it easier readable. 
8. For naming conventions, I changed all files/images to only have lowercase letters.
9. Added a overflow wrap to all headings. This makes it so long words break and move to the next line, convenient for smaller screens.
